# Политика конфиденциальности MyFit

MyFit — open-source приложение для учёта питания и активности. Все данные хранятся локально на вашем устройстве. Приложение не имеет серверной части и не передаёт ваши данные третьим лицам.

## Health Connect

С вашего согласия приложение читает следующие данные из Health Connect:

- Количество шагов за день
- Общие сожжённые калории за день (включая базовый обмен веществ)

Эти данные используются только для отображения на дашборде Дневника. Они не сохраняются в постоянной памяти приложения — кешируются в оперативной памяти на время сессии и удаляются при закрытии приложения.

Вы можете в любой момент отозвать разрешения в системных настройках Health Connect или отключить интеграцию через настройки MyFit.

## Локальные данные

Приложение хранит следующие данные локально (никуда не передаются):

- Журнал съеденного (продукты, граммы, дата)
- Журнал активностей (тип, длительность, дата)
- Справочник продуктов и активностей
- Настройки (целевые КБЖУ, тема, напоминания, времена)

Эти данные находятся в защищённом хранилище приложения и удаляются при удалении приложения или очистке его данных через системные настройки.
